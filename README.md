# Cheeky Sound Studio

Build me an app called Fart Simulator that has a pair of butt cheeks on the screen and a button you can press that makes a fart come out. you can customise the sound of the fart by changing the size and shape of the buttcheeks, you can make the butthole smaller or larger,  you can choose which foods are ingested, etc but every change creates a different sound

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://butt-sound-lab.lovable.app
